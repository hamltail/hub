## Technical Decisions

Next.js・TypeScript・Tailwind CSSを用いて制作し、作品の追加や継続的な改善を行いやすい構成にしています。

コンポーネントの分割やデザイントークンの導入、多言語対応などを進めるとともに、E2Eテストやアクセシビリティ検証などを取り入れ、品質を継続的に確認・改善できる構成にしています。

## Development

- **開発期間：** 2026年7月〜10月（以降も継続改善）
- **ソースコード公開期間：** 2026年7月〜10月

2026年7月にNext.jsを用いて制作を開始し、作品カードや基本レイアウトを実装しました。

その後、掲載作品の拡充、UI・UX、レスポンシブ対応、テーマ切り替え、多言語対応、テスト、セキュリティなどの改善を継続しています。

ソースコードは2026年7月から10月までGitHub上で公開していましたが、現在は非公開としています。

本リポジトリでは、制作実績としてプロジェクトの概要および技術構成を公開しています。
